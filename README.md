## About
This project contains a responsive, animated, and fully customizable web mockup of the **iPhone 14 Pro Max**. It demonstrates dynamic color swapping, smooth CSS animations, and easy structure for learning or integrating into portfolios and tutorials.

Perfect for:
- Frontend demos
- UI tutorials


---

## Features
- Realistic iPhone 14 Pro Max frame and screen mockup
- Dynamic color themes — change device color live
- Smooth entrance and interaction animations
- Responsive layout (works across desktop / tablet / mobile)
- Lightweight (HTML / CSS / vanilla JS) — no frameworks required
- Easy to customize: swap colors, screen content, animation timing
